# Kasir Point

Aplikasi Kasir (Point of Sale) Android berbasis Kotlin dan Jetpack Compose untuk coffee shop dan usaha UMKM.

## Fitur Utama
- **Kasir & Keranjang**: Pencarian produk, tab kategori, varian produk, tipe pesanan (makan di tempat/bawa pulang), catatan pesanan.
- **Autentikasi & Profil Usaha**: Firebase Authentication & Cloud Firestore multi-tenant per akun usaha.
- **Kelola Produk & Kategori**: Real-time sync Firestore, kelola varian & stok produk.
- **Pembayaran & Struk**: Tunai (kalkulator kembalian + tombol cepat), QRIS, Transfer, Struk visual, Bagikan Struk (Share Sheet).
- **Riwayat Transaksi & Pembatalan**: Detail transaksi & pembatalan transaksi dengan pemulihan stok otomatis.
- **Laporan Penjualan**: Filter periode (Hari ini, Minggu ini, Bulan ini, Pilih tanggal), grafik omzet harian, rincian metode bayar, produk terlaris.
- **Pengaturan**: Profil usaha, pajak, tipe pesanan, template struk dengan *live preview*.
